# Smart To-Do List Application

A command-line task management application built with Python. 

## Features
* **Interactive Menu:** Simple, easy-to-use command-line interface.
* **Persistent Storage:** Tasks are safely stored in a `tasks.txt` file so they are never lost.
* **Auto-Save:** Automatically writes data to the hard drive the moment a new task is added.
* **Error Handling:** Safely builds new files if no previous save data exists.

## Technologies Used
* Python 3
* File I/O (`open()`, read/write modes)
* Control Flow (`while` loops, `if/elif/else`)
* Data Structures (Lists)

## How to Run
1. Make sure Python is installed on your computer.
2. Run the script in your terminal using: `python TodoList.py`
3. Follow the on-screen menu to add, view, or save your tasks!
